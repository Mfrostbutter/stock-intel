# Code of conduct

## The short version

Be decent. Assume good faith. Argue about the code, not the person.

## What that means here

- Feedback is about the work: the design, the numbers, the tests. Not about who wrote it.
- Ask before assuming someone is wrong; this project touches money, and confident wrongness is
  expensive for everyone reading along.
- No harassment, no demeaning comments, no unwelcome attention. Anything that would make a
  reasonable person avoid the repository is out.
- No financial advice to other participants, and no pitching a product, a service, a signal group
  or a token. This is a research framework, and the issue tracker is not a venue for recommending
  what anyone should buy.

## Scope

Issues, pull requests, discussions and any other space that represents this project.

## Enforcement

The maintainer will edit, lock or delete a contribution that breaks this, and will block an account
that keeps doing it. If something needs reporting privately, use the contact route in
[SECURITY.md](SECURITY.md).
